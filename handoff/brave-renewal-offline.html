Brave 单次测试 · 私有记录助手

仅在本人电脑离线使用。此文件不联网、不读剪贴板、不自动保存、不发送。这里绝不能输入 API key 或密码。关闭页面会丢失输入。

本工具只计算格式和摘要，无法证明账户事实。五条日常调用仍关闭；通过后也最多尝试一次。必须等助手提供已审查的 main SHA，不能用旧版本替代。

1. 本人核实并取得指纹

在官方 Brave 控制台同一次登录中，确认当前账户身份、实际 key 属于 Search / Postpaid，以及保存的 Free credits only 已启用且覆盖所有 Search keys。不要修改付款或额度设置。

若页面没有非秘密指纹，可用下方 PowerShell 在本人本机计算。必须是无录屏、无转录的私有会话；不要关闭组织强制审计。只在隐藏提示出现后输入实际 key，绝不要把 key 写进命令。若有云剪贴板或历史，不要复制 key，直接本人输入。不要把原 key、输出指纹或生成记录发到聊天或公开仓库。

显示本地 PowerShell 指纹步骤（代码不含真实 key）
$secret = Read-Host '输入 Brave key（隐藏输入）' -AsSecureString
$ptr = [IntPtr]::Zero
$raw = $null; $bytes = $null; $sha = $null
try {
  $ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secret)
  $raw = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr)
  if ([string]::IsNullOrEmpty($raw) -or $raw -match '\s') { throw '输入为空或包含空白。' }
  $bytes = [Text.Encoding]::UTF8.GetBytes($raw)
  $sha = [Security.Cryptography.SHA256]::Create()
  $digest = $sha.ComputeHash($bytes)
  (($digest | ForEach-Object { $_.ToString('x2') }) -join '').Substring(0,16)
} finally {
  if ($bytes) { [Array]::Clear($bytes,0,$bytes.Length) }
  if ($sha) { $sha.Dispose() }
  if ($ptr -ne [IntPtr]::Zero) { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr) }
  $raw = $null; $secret.Dispose()
}

仅将输出的 16 位小写指纹填到下方。完成后关闭 PowerShell。计算中会短暂存在明文内存，不能保证消除所有内存副本。

2. 填入本次实际观察

不要猜测，也不要复用旧截图。所有时间使用 UTC，例如 2026-11-18T04:30:00.000Z。保护截止必须有依据；不清楚就停止。授权可选更早的短期限，绝不超过观察后 24 小时。

控制台只需查四个数字：本月请求次数、用量费用、免费额度、实际自付金额（均以 USD 为准）。先填有根据的保护截止，再按此按钮，可免手算观察和授权时间。不要用此按钮给旧观察重新盖时间戳。
