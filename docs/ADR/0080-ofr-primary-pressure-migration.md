# ADR-0080: OFR 主压力读数迁移提案

## Status

**Owner-selected direction / contract review in progress — owner已选择正式退役旧公开建议，并授权本次讨论issue、独立Codex代审及分项PR推送；最终合并部署待完整迁移补丁可审后确认。** 本补丁仅实施未接入的解析/读数适配器、回归测试与可审阅迁移契约，不修改任何现行评分、DESIGN、checker断言、Daily、前端、生产JSON或workflow。

## Context

现行六模块混合分数叠加尾部保底，既用于主页判读，也进入执行锁、仓位区间、动作队列及状态叙事。只替换Hero数字会使正文及行动建议继续使用旧尺度；把OFR值或百分位填入旧`score`也会误用25/40/60等旧阈值。前期研究不能证明七个自研候选一致改善，不将其包装为已通过评审。

## Decision proposed for review

1. 第一版主压力读数使用OFR官方发表的派生FSI原值，明确实际观察日与约两个营业日发布滞后；旁列严格过去十年历史百分位及约一周前变化。原值高/低于0只解释为高/低于其历史平均，不派生危机、见顶、仓位或旧档位。百分位是历史相对位置，不是0–100风险评分。
2. 基础模块、尾部/运输警报、World Order及结构证据分层展示；尾部与World Order不抬高OFR。现行历史分数/旧发布记录保留，不重标，不把口径切换的数值差当市场改善。
3. 推荐同时停止对外给出旧分数推导的状态/仓位/动作建议；保留其历史审计。若owner选择保留旧实验建议，必须另定显著隔离及冲突处置，不能默认采用。**本条是待决策选项，未实施。** 新OFR读数没有到交易/仓位的映射。
4. 新来源归属`daily_history_layer`，经`artifact_sanitizer_layer`；当前仅准备解析、单次bounded抓取能力和本地试跑。将来沿用既有Daily cadence，不增加独立调度或浏览器live fetch。任何生产接入仍按具体来源/写入审阅批准实施。
5. 原七候选及84日/40输入/12周协议保持原状。新契约发布的是机构测量读数，不宣称新自研模型胜出、概率已校准或独立危机分类准确。本ADR在Proposed状态不替代ADR-0044/0047/0053或其冻结标准。

## Concrete adapter contract

- 代码：`scripts/daily/ofr-pressure-readout.mjs`；顶层导入无网络/写入副作用，未被任何runtime入口导入。`lifecycle=prepared_not_activated`、`productionEligible=false`。
- 只用OFR公开发表的派生指数/贡献；不取得33项底层授权数据、不使用官方徽章、不暗示背书。权利核查依据[官方法律说明](https://www.financialresearch.gov/legal-notices/)；来源归因/第三方限制保留。
- 精确CSV schema、严格日期/排序/去重/有限数；真实0有效，空值保留null。最新一期总值缺失时显示缺失，不静默以旧值充当本期。
- 原始FSI不clamp到0–100、不用贡献重建总值；原始字节SHA和retrievedAt独立于observedDate。旧快照不改写；相同日期数值修订与null/zero可得性变化单列。
- 7个日历日年龄仅为保守发布屏障提案，不冒充美国营业日/假日release clock。失效保留带日期的旧观察并退出当前主判读资格，不回退到旧综合分制造平稳。
- 百分位：`100*(低于当前值的历史条数+0.5*相等条数)/有效历史条数`，窗口为观察日之前十个日历年、排除当前/未来，至少2000条，起点距窗口开始≤7日、最大间隔≤14日。不足只使辅助百分位缺失，不抹掉有效官方原值。工程覆盖屏障不是经济状态阈值。
- 周变化：观察日之前7日为目标，取不晚于目标且距目标≤4日的有效值；同时显示实际端点。不能以0替代缺失。

## Consequences

主位含义明确、有可核对来源，但存在来源集中、发布延迟、历史修订及宏观/流动性覆盖局限。派生百分位随参照窗口变化；不将平静期相对高位当危机。不承诺替换即获得危机预测准确率。部署资格需看实际补丁及审阅，不由本提案或检查通过自动取得。

对实际退役JSON投影运行完整保护网时，旧`check-external-ai-provenance-completeness.mjs`仍强求已退役的`externalAiInterpretationLayer.provenance`。现新增严格的模型分支：必须先通过完整`validateOfrPublicationIfPresent`（新主读数、完整退役对象、无旧AI字段/仓位/风险预算），才接受旧字段缺席；半套字段、仅mode标志或旧AI复活都拒绝。原旧模型全部溯源断言及disabled-fallback分支不改，新增CLI stdin正反例验证。该变化是本次明确契约迁移的一部分，须独立审阅，不作为宽泛skip。
