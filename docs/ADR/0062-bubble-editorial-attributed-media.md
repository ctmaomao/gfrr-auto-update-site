# ADR-0062: Bubble 周度专业媒体归因与有限证据简版

- 状态：Owner-approved implementation baseline; pending independent review before merge
- 日期：2026-10-06
- 批准：owner 同意执行本次来源审查建议；不包含发布或真实付费调用
- 范围：仅 Bubble 周度展示层的新闻资格、归因、简版数量及长度；窄范围替代 ADR-0021 / 周度设计的旧资格规则

## 问题与决策

本周搜索健康却因全部候选被标 discovery_only 而零调用跳过。加州司法部官方公告被域名清单漏识别；专业媒体单源报道也无法进入独立展示层。

1. 精确补登记 oag.ca.gov；不泛化所有政府域名。
2. 新增 attributed_media，与 official/cross_checked 区分。登记 Morningstar、FT、Bloomberg、CNBC、Reuters、WSJ、The Information 的明确域名，含子域名、排除已点名社区/论坛/评论/sponsored 路径。必须有本期检索窗口内有效日期和至少 80 字符可用摘要，付费墙提示不合格。此列表可审阅，不声明所有其他来源不可信。
3. 每个引用专业媒体的事实段落必须点名 sourceName 并有中文归因语气；数字及引述必须出现在提供的标题/摘要中。保留意见和不确定性，不补写全文，不把媒体观点改写为独立确认。仅标题/订阅提示不进入正文事实。
4. 仍至少引用一条可用新闻及五项指标。少于两条可用新闻时允许简版：时间线可为空，至少一项矛盾、两类分析及两项下周观察，600–6500 字契约/600–1800 字生成目标；必须披露新闻覆盖缺口，置信度 low/medium 且 ≤70。完整判读原门槛不变。
5. 生产来源账本保留来源名称和 contentScope，仍不保存摘要。摘要字面数字/引述检查在输入可用的输出验证与 projection 阶段执行；生产回读验证元数据和归因，不声称重新验证已丢弃的摘要。机器规则不是完整自然语言事实核验。

## 保留边界与验收

不改评分、决策、执行、仓位、数据源请求数量、workflow、生产 JSON、单次调用/不重试、费用批准、freshness、unsafe/未知引用与 writer 路径保护。零可用新闻仍 expected skip，搜索服务异常仍 hard fail。

新增回归覆盖官方漏识别/相似域名、单源媒体准入、标题与订阅提示拒绝、归因/数字/引述/未知引用负例、简版缺口和置信度、生产账本无摘要及 writer 不修改其余数据。保留现有负例，不增加 skip/ignore。本任务是独立契约变更，合并前仍须独立 review；本地全绿不代表上线或真实 provider 成功。
