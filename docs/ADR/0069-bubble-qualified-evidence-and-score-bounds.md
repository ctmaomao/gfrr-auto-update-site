# ADR-0069: Bubble 四项证据迁移与固定 Core-23 不确定区间

- 日期：2026-10-13
- 状态：owner 已授权依次修订；契约候选待独立审阅，尚未启用 runtime。
- 范围：ABS → 内部人交易 → capex 指引事件 → Fed 市场路径。仅 Bubble 专题，不影响 GFRR 主评分/决策/执行/仓位。

## 问题与批准基线

owner 在逐项评估后要求“请按你的顺序一一修订”。现行中国 AAA ABS 绝对收益率不是美国数据中心信用利差；内部人升红确认字段没有生产者；滚动股价相对表现不是指引事件反应；SEP 官员情景及合约月份平均 EFFR 不应混同市场年末政策概率。前序 CEO 修复已经 PR #455 合并 c1723265，不在本迁移中重写。

本轮采用固定 23 个核心槽位、4 个影子槽位；不缩分母，不用缺失代替绿灯。保留现行 25/40/60 主分档及分类/两轴升级规则，不为匹配参考站调分。零新依赖、零新增收费调用；正式生产数据由既有 builder 生成，不手改 JSON。

## 决定

1. 新发布采用 `bubble-watch-v3` 与 `bubble-watch-v3-core23-shadow4-r1..r4`，分别对应上述四个累计迁移步骤；旧 v2 payload 及历史仍按原契约验证。不同 revision 不混合为同口径趋势，不回写旧历史的原模型/原分。
2. 仅已迁移的上述核心指标可用 `status=unknown`。必须带指标精确匹配的 `evidence_gap.reasonCode`，以真实检查时间披露缺口；缺观测日为 null，不把检查时间当原始观测日。非登记指标、影子项、非法状态和字段缺失均拒绝。
3. 已确认红/黄/绿与待确认分别计数，固定分母为23。存在核心缺口时主分/辅助压力点值为null，发布下界与上界；下界只是假定缺口全部为绿的极限，上界假定全部为红，不给缺口赋实际灯色。两轴/分类也按原固定集合计算区间，受缺口影响的点值为null；不受影响的轴可保持真实点值。
4. 现行档位升级规则对灯色严重度单调；两端补全给出最低/最高有效档位。仅两端档位一致时，允许给出该档位并明确披露主分缺口；不一致时显示“判读待确认”，不得发布无依据的单一档位。区间不是概率或置信区间。
5. 新 checker 必须独立重放点值、计数、区间和档位，并拒绝缺口点值=0、缩分母、把待确认计为绿、篡改上下界、未来阶段提前启用以及影子影响评分。旧 v2 的数值/来源/时效/非影响保护保留。本契约及 checker 变更使用独立 reviewed PR；runtime/展示集成另行提交，不把 assertion 变更藏在展示补丁中。

## 各步证据要求

- **r1 ABS**：中国通用 ABS 只能保留为注明市场/日期的背景，不生成美国数据中心利差灯色。合格信号需来源准入与核心代表性分别批准、同币种/债项/分层/期限口径的可比较数据中心利差及真实观测日；每个债券/基准报价必须同日且分别来自获审来源；缺少合格输入时待确认。新闻、票息、公司贷款价格及通用绝对收益率不补位。当前没有新的美国连续报价源连接，不以本契约授权付费采集或绕过 source rights。
- **r2 内部人**：固定扩大后的公司篮子及30/90日窗口；仅公开市场P/S美元金额，保留计划性交易披露。升红必须实际验证全部标的、完整窗口、无记录截断及非近零分母；覆盖/分母不足保留保守保护。不能通过手工置二次确认布尔值解锁。阈值暂保留20x/5x，不声称已校准为泡沫预测阈值。
- **r3 capex**：具名公司、公告原时间、同口径前后指引、匹配首个完整交易日及基准收益。财报还包含其他信息，文案描述公告后反应，不归因全部超额收益于capex。没有合格事件不是“奖励”；滚动多窗口只作辅助，不代替事件输入或独立升红。
- **r4 Fed**：固定3/6个月市场路径，按官方会议日与月份平均EFFR关系解析期末路径，使用当前EFFR可比基准。SEP及下次会议是独立背景，不独自生成市场路径红灯。报价/日历缺失或过期不得由旧SEP/DFF+CPI拼出当前市场期望。

## 回放与展示

冻结2026-10-12旧模型灯色，只用于离线比较。ABS待确认时，主分30.4–34.8%、辅助压力45.7–50.0%、Trigger34.6–42.3，Stage60.0；分类共振在所有补全下仍支持高风险预警。此结果是当前快照区间重放，不是历史预测有效性验证，也不是生产新报价。

旧周报多只保存灯色，无法据此补造新窗口/指引事件/政策曲线。迁移报告必须分别列完整新口径覆盖与仅有旧口径状态的周数；禁止用当前数据回填旧周。新历史从合格原观测开始累计，保留不同模型的原记录及来源时间。

展示沿用 DESIGN.md §2/3/4.4 的纸色、墨色、三字体栈和27卡结构。待确认为中性状态，Hero显示后端区间与缺口，renderer不重算判读。AI编辑输入必须保留null/区间/缺口，不把下界当点分；本任务无provider调用。

## 授权边界与恢复

本次授权是上述四项实施及必要验证；来源资格、费用和生产写入保护保持独立。前序“其它指标不改”在这四项批准范围由本决定替代，其他指标不变。每步先通过契约/独立审阅再接入runtime；owner 已明确授权四项独立 AI 代审、推送、合并上线；每步以无阻断审阅和 CI 通过为集成条件。

回滚使用对应集成提交的正常revert，不改历史快照或伪造观测；不强推、不删除分支/用户文件。已发布v2页面和JSON在v3实际刷新前保持兼容；已有v3产物时，回退采集方法须保留v3读者和checker，不把nullable产物交给旧版页面。
