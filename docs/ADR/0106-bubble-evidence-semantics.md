## Context and acceptance baseline

The owner asked to continue fixing the AI generation path. Independent factual review of the new Bubble issue found source meanings inherited from deterministic input: SEC `RevenueRemainingPerformanceObligation` was labelled deferred revenue; subtracting SPY and RSP percentage returns was labelled percent; a registered issuance/pending-issuance pipeline count could read as completed IPOs; broad HY OAS was presented as direct AI capex risk pricing. A November 9 article about a company founded during summer also supplied the timeline date without identifying that date as the report date.

The raw transient input/snippets for that run are unavailable. This patch is not a replay or repaired AI article. Quarantine is a separate coordinated change. No provider/search call, new fee grant, budget reset, source expansion, browser action or production refresh belongs to this implementation.

## Decision

1. **Correct source labels, not calculations.** `cloud_rpo_growth` means remaining performance obligations (RPO)/backlog, not deferred revenue or recognized revenue. Keep the existing companies, period matching, sums, YoY values, thresholds and score membership. Describe differences in company business scope, definitions and fiscal periods. `spy_vs_rsp_6m` remains SPY return minus RSP return, with the same signed number and absolute-magnitude color thresholds; its display and thresholds use percentage points. Individual ETF returns remain percentages. Both are S&P 500 weighting variants; RSP is not a small-cap index. This does not approve the economic symmetry of the existing absolute-magnitude scoring rule.
2. **Disclose pipeline and proxy limits.** The published IPO company count uses the registered trailing-six-month deduplicated issuance/pending-issuance snapshot. It is not completed IPO count or number of filings. The SEC confirmation scan separately covers 365 days and can include unpriced S-1/A; it does not verify that all counted firms completed issuance. HY OAS remains broad-market ICE BofA/FRED credit context, not an AI-specific basket or direct proof that AI capital-spending risks are priced/unpriced. No source or scoring policy changes.
3. **One deterministic projection for current copy.** Builder/public notes and compact facts use shared semantic labels. Compact deterministic narrative also replaces indicator-bound old display units; source digests still bind the original payload. The pure `repairCurrentBubbleEvidenceCopy` helper can repair only the four current indicators, their matching deterministic narrative text and evidence highlights. It refuses an active `summary.weekly_editorial`, verifies signed-return provenance, performs no I/O, leaves all numeric fields, scoring, timestamps and provenance unchanged, and never traverses historical editorial output. Applying it to a published snapshot is a separate coordinator-reviewed operation with a known target hash. After #537 quarantine merged, the coordinator authorized applying this pure repair to the current structured JSON in a fresh worktree. The receipt below records that bounded change.
4. **Bind every new timeline date.** The evidence pack has publication dates, not verified event dates. A news row must match the calendar day carried by a cited usable story's publication timestamp (the existing collector normalizes timestamps to UTC; this gate does not recover publisher-local dates); its source reference must match the story's URL, publication timestamp and class. The title must frame a report/disclosure/publication. Detail starts with the actual date and explicit reporting attribution, for example `2026-11-09 据媒体报道，…`. An official source may use `据官方发布，`. No date inferred from fetch/generated clocks, unrelated stories, discovery-only evidence or a headline can pass. Structured-only rows bind a cited fact's observation date and visibly identify a site observation/snapshot. Unsupported rows may be omitted; there is no new quota or automatic prose rewriting.
5. **Strengthen only bounded assertions.** Add real-calendar/date/source checks and a bounded same-day-event rejection (including “当日创办”). Add a narrow guard for explicitly named SPY−RSP/relative-lead difference claims written with `%`; legitimate individual ETF returns remain allowed. General numeric-equivalence policy, all pre-existing date/financial/quotation/source/freshness/length assertions and final writer revalidation remain. This is not complete natural-language factual verification: reporting prefixes do not independently verify every claim or detect every possible paraphrase of a false date/unit.
6. **Keep immutable history readable.** New assertions run on full transient input before review, projection and final writer admission. Existing production/history metadata-only revalidation cannot reconstruct discarded excerpts and keeps its old rules. This is not a new-write bypass: the writer still requires full input/news/output evidence, current target digest, original provenance and clocks. Existing bad prose is quarantined separately, never edited, rebound or promoted as a manual artifact.
