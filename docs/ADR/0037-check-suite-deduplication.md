# ADR-0037: Preserve checks while removing duplicate execution

- Status: Owner-authorized audit remediation; independent checker/merge review retained.
- Date: 2026-09-09.
- Scope: Step 4 check wiring and associated documentation only.

## Decision

Remove the direct `check:gdelt-web-ngrams-frontend-aggregate-health` and `check:gdelt-web-ngrams-automated-display-cache` invocations from `check:all`. Both remain in the existing `oil-directional` suite, which `check:all` already executes. Standalone `check:oil-directional` retains its full domain coverage; all leaf assertions, failures and ordering within that suite stay intact.

The P63 check's wiring assertion now requires the complete `check:all` → `check:oil-directional` → suite → P63 path instead of a direct textual reference in the top-level command. This assertion-location change requires independent review; it does not remove the check. An offline graph test requires both GDELT entries exactly once from both full and standalone entrypoints, and rejects missing script/suite references or cycles.

## Documentation

README is the small daily-use entrypoint, package.json remains the command authority, OPERATIONS explains side effects and current runtime diagnosis, and INDEX/MILESTONE_INDEX/PROJECT_COMPLETED_HISTORY distinguish current authority from history. Preserve historical files and permissions. Correct current static-homepage versus Worker descriptions and disclose the ignored analyst input generated by full checks.

## Verification

Compare expanded leaf-command sets before/after, execute the graph test and unchanged P63 guard, then run full checks. No production data, dependency, source, runtime or deployment change belongs to this step.
