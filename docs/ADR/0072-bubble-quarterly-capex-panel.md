## Numerical rubric and replay

This is a new descriptive rubric, not a validated forecasting model or an inherited upstream formula. Require all four material/timing/price rows; missing evidence holds unknown without shrinking the denominator. MSFT is a verified non-raise row. META is a lower-bound raise; AMZN/GOOGL are comparable within-issuer raises. No comparable raises means unknown.

For a comparable raise, a negative actual stock return and **strictly less than−5pp** stock-minus-QQQ adjusted return count as punished. At least3 punished events is red;1–2 is yellow. Green requires at least2 raises and **every raise** having positive stock return and excess return strictly greater than+5pp. Other neutral/mixed outcomes are yellow. Equality at±5pp does not count as punished/rewarded. Threshold comparison uses exact rational arithmetic over the source JSON numbers' decimal representations, including exponent notation; binary-float display calculations cannot push an equal boundary over the threshold. Absence of punishment is not affirmative reward. Reference-site agreement is not an acceptance criterion.

Fetch one common bounded Yahoo QQQ response plus four stock responses. Store the two actual selected NY dates, source timestamps, raw/adjusted closes, volumes, current-vintage adjustment policy and recomputable returns. These are historical latest-vintage adjusted prices, not a point-in-time backtest. Strict nested field admission permits only derived facts; raw body/HTML, authorization and other unknown fields are rejected at panel/company/catalog/guidance/timing/window/price/request/budget levels. The limitation string is fixed, and no arbitrary text container is admitted. The independent replay binds all19 source requests, canonical event registry, scope, dates, clause/document digests and reviewed annual amounts, reconstructs each event window and raw selected-price calculation, checks common overlapping QQQ observations, then recomputes the decision. A digest binds recorded material; it does not prove publisher authenticity or independently re-fetch that source.

Actual local collection:19 requests, zero failures,4 qualified rows;3 raises,2 punished,1 rewarded, yellow. Excess returns approximately MSFT+12.2093pp (not counted as raise), META−11.2515pp, AMZN+14.6710pp, GOOGL−5.2343pp. Retain original July event dates, not October as an alleged earnings date.
