# ADR-0120 · 信用变化的观测周期

- 日期：2026-11-17
- 状态：本轮宏观数据修复授权；独立审阅与完整检查后集成

## 决策

无界最近邻可把 NFCI 一周变化标为四周，或把 SLOOS 缺季标为零。NFCI 必须有整 28 日前的唯一数值观测；SLOOS 必须有上一日历季度起始日的唯一数值观测。当前日期亦须唯一且规范。缺失返回 null，真实零保留。

SLOOS 两个既有请求由 180 日延长至 270 日：10 月新调查公布前，4 月参照会被 180 日窗口裁掉，而最新仍是 7 月。只改变 observation_start，不新增请求、来源、费用或重试。缓存变化缺参照日期证明时不复用，已有水平和日期仍保留。

## 明确替代的检查契约

`check-macro-drivers-credit-sloos.mjs` 的两个精确请求标记从 180 改为 270；其余字段、来源、隔离与数据断言全部保留。不是任意窗口许可。真实 resolver 的发布延迟测试另验证 270 日及正确季变化，缺季仍关闭。

不修改评分、阈值、生产数据、前端或其它最近邻调用者。来源频率及最小实样见 [DATA_SOURCES](../DATA_SOURCES.md)。上线代码不等于下一次自然生产已验收。
