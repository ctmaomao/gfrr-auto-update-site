# 免费 Events：World Order 评分接入设计与离线影响回放

## 授权与本轮边界

2026-10-10 owner 明确否定仅展示方案，要求免费 Events 参与量化分析，并批准开始
评分接入设计和离线影响回放。本轮可实施独立研究工具、离线回放与方案记录；
不改变生产评分、校准、JSON、前端、workflow，不 push/merge/部署。
这不是仅展示方案，但离线计算结果仍不是生产模型批准。

## 拟议指标与接入范围

- 主输入：完整 UTC 七日、发生日也在窗口内、按事件 ID 去重的 CAMEO 18–20 类
  已分类暴力新闻编码记录。保留全球发生地 FIPS 范围及未知发生地披露。
- 主输出：相对固定训练尺度的冲突新闻编码强度，不称真实冲突次数、战争概率或收益预测。
- 量化进入两个冲突相关通道：和平红利退潮中现有 GDELT 权重 0.20、多战区冲突中
  现有 GDELT 权重 0.70；SIPRI、ACLED、模块与全局权重保持当前定义。
- 阵营化、经济金融武器化、资本管制三维度不能使用暴力记录替代证据。
  本方案回放将它们固定在基线，尚未完成这三个旧 Cloud 通道的来源迁移。
  后续应独立审阅对应来源/权重，不能填零、随意重分权重或伪称全部 Cloud 模型已替换。
- 七日变化使用相隔七个日历日的窗口，底层源日期不重叠；国家分布作统计证据，
  本轮不设置任意国家数量阈值或给地域广度额外加分。

## 未知分类与区间政策设计

保持既有严格资格规则：缺文件或坏行时 `statisticallyQualified=false`，旧单点
`proposedReferenceScale=null` 不变。新增研究区间不是把旧检查放宽成通过。

对 672 文件齐全且无冲突/歧义 ID 的窗口，设已分类暴力记录数为 L、隔离行数为 U。
研究计数界为 [L,L+U]：最坏情况下每条未知行都是窗口内一个额外暴力记录；重复或
窗口外未知行可能使上界偏宽，但不把未知默认为非暴力或零。缺文件数量没有可靠上界，
此时整个评分候选保持 null；矛盾/歧义 ID 同样 hold。

训练期的 30 个窗口分别计算计数上下界，中位数界为 [Slo,Shi]。用同一饱和函数得到
得分界 [100*L/(L+Shi),100*(L+U)/(L+U+Slo)]。参考尺度必须正；不得在线重拟合或
通过检验期选尺度。尺度与输出都是研究界，`pointScaleApproved=false`。

未来生产合同可审议区间认证：只有证据完整、区间可靠且经过模型审阅，才让整数
总分上下界相同的窗口使用共同分数；若区间跨分值/状态门槛，保留区间或 publication
hold，不制造单点确定性。该政策尚未批准，也没有生效于任何现行 checker/runtime。
失败仍保留带原日期的可用证据，freshness 独立检查，不能用生成时间续期。

## 回放方法与可复现入口

```powershell
npm run replay:gdelt-events-score-impact
npm run replay:gdelt-events-score-impact -- --write-report
```

默认完全离线、无写入；显式写入也只落 ignored research-v2 唯一报告，不覆盖既有
报告，没有网络/任意输出路径参数。最多读取 49 个每份 <=40 MiB、总量 <=256 MiB
的 sanitized 缓存，未来或未完成 UTC 日参数会被拒绝。
校验每日 digest/语义、完整窗口与连续日期/训练检验隔离；缺资料不补零。

基线从本地 origin/main 最后修改 World Order JSON 的提交读取，同提交取规则和
radar-data，固定市场/OFAC/SIPRI/ACLED/模块背景。实际基线提交
`60f58f24c0e2e39bfc5629cb5e57f28a19c50343`、updatedAt 2026-10-09T02:45:30.716Z。
运行时检查本地评分依赖与该提交无差异，生产 composer 复算的总分/状态/各维度必须
与已发布快照完全一致，否则拒绝回放。输入与每日缓存 digest 写进报告。

用旧公式的逆变换构造一个仅在测试内使用的合成通道分数，再调用未改动的生产
composer，保留其精确舍入。合成分数不是观测数据、新闻记录或可发布 source。
针对性候选只取两个冲突维度的结果；其余三个维度取真实基线。小段模块权重组合
另有基线重建 parity gate，防止研究副本漂移。

## 实际结果

原预定 cohort：2026-08-20–10-07 的 49 源日，训练结束日 08-26–09-24，六日
隔离，检验结束日 10-01–10-07。4,704 文件/4,818,952 行，09-08 一条、10-06
两条分类异常；严格训练资格 23/30、检验资格 5/7，原单点资格没有被修改。
研究参考尺度界为 **49,529–49,529.5**。

| 方案 | 固定背景下的总分 | 状态 | 含义 |
|---|---:|---|---|
| 现有基线 | 52 | 阵营化与脱钩期 | 旧 Cloud 通道分 21，已按 stale 折扣 |
| 仅替换两个冲突通道 | 56 | 阵营化与脱钩期 | 推荐继续审阅的量化候选 |
| 用新尺度但替换全部五通道 | 59 | 阵营化与脱钩期 | 暴力记录污染非冲突维度，不推荐 |
| 免费原始数直接套旧 Cloud 尺度 | 71 | 多战区压力期 | 换源失真，不推荐 |

七个检验窗口的针对性候选，在主尺度下均为 56。10-07 窗口的计数界
51,817–51,819，通道得分界 51.128554–51.129771；总分上下界同为 56。
和平红利退潮维度 57→63，多战区冲突 33→54；其它三维度保持 54/70/62。
把参考尺度乘 0.5/0.75/1/1.25/1.5 做预设敏感性网格，候选总分范围为 **55–58**，
七个窗口均未跨状态门槛。没有按结果挑选最能提高分数的尺度。
52→56 同时涉及源口径、新尺度和旧 stale 折扣的替换，不是现实金融风险新增四分；
迁移前后历史分数不能直接当作同口径趋势比较。

这些结果表示三条未知分类对本样本的数值影响很小；它们不认证数据没有其它编码
误差，也不认证该分数有金融预测能力。不能据此抬升置信度或解锁生产。

## 限制与下一次独立模型审阅

- 这是固定近期背景的反事实敏感性回放，不是历史全量 World Order 序列、收益回测
  或前瞻预测检验。训练内部滚动窗口重叠；方案已看过样本，检验不是盲测。
- 绝对记录数会受新闻量/语言覆盖/抽取系统影响。现有缓存没有所有类别按相同发生日
  与唯一 ID 过滤的完整分母，不伪造新闻量归一化比例；需较长观察和来源稳定性审阅。
- 全球口径含大量国内暴力，发生地不等于战争国家。多战区维度只是新闻编码压力代理，
  不能称已核实多战区战争。DOC/Web NGrams 不能填充或校准冲突数量。
- 三个非冲突维度仍依赖历史 Cloud 通道；本候选不是全模块来源迁移完成。
- 推荐独立审议两个冲突通道、冻结训练期尺度区间、未知行区间认证与时效/失败保护。
  接着实施单独的 production adapter/评分合同、来源缓存与每日增量工作流，按 CI、
  独立 review、发布与线上验收推进；不从本轮通过推断这些步骤已获批准。
