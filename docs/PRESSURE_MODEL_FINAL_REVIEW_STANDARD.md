# 压力模型最终评审标准 · 2026-09-18

## 状态、目标与冻结点

Owner 在本轮明确要求“固定最终评审标准”，本文件把 [ADR-0044](ADR/0044-contemporaneous-pressure-research.md)、[ADR-0047](ADR/0047-pressure-evidence-continuity.md) 和[整改验收](PRESSURE_EVIDENCE_ACCEPTANCE_2026_09_18.md)转成可执行的人工评审清单。它不修改运行时闸门，不授权自动替换生产模型，也不新增取数或付费调用。

目标固定为：通过美国市场代理衡量同期市场与宏观压力。不得据此宣称覆盖全部全球金融系统、预测危机、校准危机概率或优化仓位；分数较低本身不是改善。采用 backtest-expert 的全样本、稳健性和样本外分离原则，不套用交易策略的收益/交易笔数门槛。

冻结时已看过历史结果和新批次首日，不能宣称整个研究从未看过数据。后续不得按观察结果改候选、阈值、代价比、参考指标或本清单的选择口径；必要修订另行版本化，注明看过哪些结果及生效日期，不追溯覆盖旧结论。修改模型/协议须保留旧批次并遵守新批次规则。

- 协议：[pressure-model-research.json](../config/pressure-model-research.json)，七个候选完整保留，研究报警为分数 ≥ 70，参考正压力为指数 > 0。
- 两个参考：STLFSI4、NFCI，分别报告，不事后择优、不平均成一个总分；两者共享市场输入，只是收敛性参考，不是独立危机真值。

## 1. 先判断证据能否进入评审

| 检查 | 必须记录的事实 | 未满足时的结论 |
|---|---|---|
| 原有收集闸门 | 至少 84 个经过日、40 组不同市场输入、12 个匹配基准周；附原报告字段 | 继续观察，不进入替换结论 |
| 批次完整性 | workflow run/提交、artifact、协议/模型/ledger 哈希；时间、源年龄、特征与分数重放、哈希链验证 | 停止评审并排查，不能补写、修改旧记录或清空批次掩盖问题 |
| 同口径样本 | 全候选与旧回放共同日期、各模型/参考有效周数、缺失/暖机周与剔除原因 | 缺失保持不可评估；不同窗口的结果不能直接排名 |
| 可辨识性 | 每个参考的正/非正周数、不同连续压力段数、日历缺口 | 没有正压力周不能证明捕捉压力，没有非正周不能证明控制误报；单一事件不足以说明跨情景稳定 |
| 基准版本 | 基准抓取时间、匹配观测日期、首次保存报告与最终报告间的修订差异 | 最新修订参考不得冒充当时发布值；无法重建的版本标记未知 |

84 日/40 输入/12 周只是最低收集要求，不是统计功效保证。当前 `bootstrapAgreement` 不满 26 个配对观察时不输出相关性区间；达到 26 也不自动充分。它只给相关性的回溯性区间，不是候选与旧模型加权错误差的显著性检验，也不是七候选择优后的置信证明。不能用缺失区间、区间重叠或两个单独区间的差替代配对差检验。

因此最早收集时间门槛为 2026-12-10 UTC，源缺失、基准发布滞后或压力情景不足可令最终评审继续延期；不承诺到期更换评分。任何新增推断方法或数值容忍限均须先写明方案和版本，不在最终结果出来后临时调参。

## 2. 比较对象与主要判据

主比较继续使用同日期、同共享源滞后假设的 `legacy_assumed_lags`；它是旧规则回放，不是完整当时生产快照。若另取真实发布分，必须单列其来源、时刻、运输与结构输入差异，不能混入这一基线。

每个候选在每个参考下完整列出：TP/FN/FP/TN、正压力周数、灵敏度、特异度、AUROC、秩相关、加权错误、可用不确定性说明。分母为零则为 null；不将 null 当作 0 或优胜。

主要比较量沿用既定代价比：`L = (2 × FN + FP) / N`，并给出 `ΔL = L候选 − L旧回放`。2:1 是研究操作约定，不能解释为真实投资损失或最优用户偏好。相关性和 AUROC 为辅助，不用来推翻主要错误代价比较。

进入“值得独立模型评审”的性能筛选口径是：在共同前瞻样本中，候选对两个参考的 ΔL 均不大于 0，且至少一个严格小于 0；同时两参考的 FN 均不得增加。若为了减少漏报而增加 FP，必须同时列出减少的 FN、增加的 FP 以及持续误报负担，不能只展示净代价。该筛选只是描述性必要条件，不证明统计显著、实际投资价值或生产替换资格。

若两个参考方向冲突，结论是目标/测量差异待解释，不选择更有利的参考。七候选全部展示；没有候选满足就记录没有改善。多个满足而差异证据不足时，保持并列待评审，不以小数点后的排序宣布赢家。更复杂的相关性调整或尾部权重必须显示可复查的增益，否则优先保留简单模型作为讨论基线；这不是自动选中等权候选。

## 3. 报警持续时间和跳变负担

采用固定的周频共同匹配窗口评价报警；真实日记录另作运行诊断。两种频率分别呈现，不能把每日记录当作独立基准周扩大样本量。

- **连续误报/漏报**：按七日连续、相同 FN 或 FP 分类划段。正确周、缺失周或超过七日的断档结束该段；每段记录开始/结束日、周数及是否在样本边界截断。列出全部段、总周数、最长段和中位段长，不只挑成功案例。
- **压力段覆盖**：参考 > 0 的连续周构成一段；列出整段未报警的段数，以及首次同周报警距离该段首周的周数。缺周打断、末端未结束标记截断。此为同期识别延迟，不是提前预测能力。
- **来回切换**：只在两条连续有效观察之间计报警状态翻转；报告翻转数/有效相邻对数，日频与周频分开。缺失与断档不当成恢复正常或解除报警。
- **分数变化**：逐个真实相邻区间保留输入先换/校准先换的双顺序记账、校准独自造成的下降、参考窗口滚动、源修订与间隔日数；不能把纯校准降分称为市场改善。

持续负担是独立审阅项。即使 ΔL 改善，若出现更长的误报段、更多完全漏掉的压力段或更频繁的阈值反复穿越，必须明确解释影响；未解决则继续观察。现阶段没有经过验证的“可接受连续报警天数”，不凭空添加天数或比例阈值。

## 4. 信用代理、历史与稳健性

历史结果只用于解释及反例，不能与前瞻记录合并计算收集闸门或替代前瞻结论。359 个历史共同周中的 207 周旧回放使用 BAA10Y 代理，152 周有原始 HY OAS；这不是同等历史生产输入覆盖。

对每个参考、每个候选分别报告：全体、旧回放 HY 原始可用、旧回放 HY 代理三个切片，以及按年结果；每个切片给出 N、正压力周数和混淆计数。前瞻记录也按其保存的旧回放输入来源分组。仅历史代理组改善不能支持“优于真实旧生产”；原始组缺少正压力样本则保持不确定。分组与历史时期重合，不能宣称代理本身导致差异。

稳健性清单包括：既定七候选的方向是否一致；分期/事件结果是否依赖单一时段；源滞后、缺失、最新修订和固定输入/移动校准的敏感性。现有额外三日滞后统计只覆盖 `diversified_156`，不得冒称七候选均验证；现有 ALFRED 缺口不得用最新 FRED 填充。任何新实验作为单独诊断，披露设计时间和已知结果，不从中事后调出第八个赢家并沿用旧样本资格。

## 5. 最终结论与迁移边界

| 结论 | 使用条件 | 后续 |
|---|---|---|
| 证据不足，继续观察 | 任一收集/完整性条件未满足，压力情景不足，修订或缺失影响未解决，或优势无法与不确定性区分 | 保留冻结方案，说明具体缺口；不称模型失败或通过 |
| 尚未显示一致改善 | 证据可比较，但主要筛选不满足、参考方向冲突或优势只见于代理历史 | 保留生产公式；新设计另立实验，不调整旧样本来追求通过 |
| 有条件进入独立模型评审 | 主要筛选满足，持续负担、覆盖、稳定性及限制都有可复核解释 | 独立评审实际文件和证据后再决定是否准备独立迁移方案 |

所有结论均不自动改变 `eligibleForProduction=false`、`productionReplacementEnabled=false` 或主站评分。正式迁移仍须独立评审、owner 对具体方案批准、版本/历史衔接、回滚方案和生产验收；本文件不是迁移授权。
