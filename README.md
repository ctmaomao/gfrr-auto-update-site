# 全球金融风险雷达 v22.2

全中文机构级静态宏观风险驾驶舱。

## 本版新增
- 30日时间维度与传导速度
- 机构级预警系统
- 资产收益 / 回撤映射
- 全宽全球风险热力图
- Node 24 GitHub Actions 工作流

## 部署
1. 上传全部文件到 GitHub 仓库根目录
2. Settings -> Pages -> Source 选择 GitHub Actions
3. 运行 `Build Daily Radar Data`
4. 再运行 `Deploy Static Site to Pages`
