# GFRR 每周周报归档政策

- 发布频率：每周一新西兰/奥克兰时间上午9:00的自动任务负责研究、制作和发布。所有日报、Bubble Watch及原风险评分链保持独立。
- 内容格式：每期独立完整UTF-8 HTML：`weekly-reports/YYYY-MM-DD.html`。内联排版，正文离线可读，不引用运行时数据接口；保留来源、观察日期、事实/推断/情景区分及必要的局限声明。
- 目录入口：`weekly-reports/index.html`。始终按日期倒序排列，最新一期置顶，链接到固定不覆写的日期URL。
- 保留期：最多保留最近**52期**（约52周）。只清理超出52期的最旧期次；若当周任务没有成功完成或发布验证失败，则**禁止删除**任何历史正文。
- 清理前置条件：1) 本周正文写入仓库；2) 历史目录更新；3) Pages部署成功，且公开页面可访问；4) 原始周报可从Git提交历史恢复。满足后才能删除超龄HTML、同步更新目录、再次验证部署。
- 缺期、来源失败、数据质量不佳：保留该期不完整发布说明或明确报告生成失败，不允许以旧数据伪装为新数据。
- 保留期是对公开Pages版本的约定。Git仓库历史不是不可变的外部备份；如需长期保存，另行定期离线导出。
- 标题中的评分不得把GFRR内部模型数字伪装成官方压力指数或危机发生概率；首页实际采用的OFR主位也不应被周报误述。
- 每期发布后同时向用户提供可下载的单HTML文件链接，并报告仓库提交/Pages部署的真实状态。
